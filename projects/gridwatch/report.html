GridWatch in Power BI

Explore the same hourly market data with a zone selector, price spread chart, comparison table, and three summary cards.

Download the Power BI project ZIP ↓Download the Fabric SQL ↓

Open and refresh the report

  1. Extract the entire ZIP and keep both project folders beside GridWatch.pbip.
  2. Open GridWatch.pbip in Power BI Desktop and refresh. If prompted, choose Anonymous for the public GitHub CSV.
  3. Select one load zone or the system series before comparing totals. The system series includes all of New England, so adding it to the zone rows double-counts scope.
  4. Compare the selected zone’s annual mean absolute spread against the browser dashboard.

The ZIP includes PBIR visuals, an import model, Power Query, and DAX. The report source is generated programmatically and has not been opened in Power BI Desktop in this environment.

Use the same data in Fabric

Copy the published hourly CSV into a Fabric Warehouse table named dbo.GridWatchHourly, using date for the local date and decimal types for price and demand columns. Run the supplied SQL to create a monthly reporting view. Reconcile a zone’s row count and mean absolute spread with the web dashboard before connecting Power BI.
