How the benchmark works

Fit on normal boards

Build a reference bank from normal VisA PCB1 images. Compare handcrafted color and texture patches with frozen ResNet-18 embeddings.

Calibrate separately

Set each method’s cutoff at the 95th percentile of scores on separate normal calibration images. The official test set stays outside fitting and calibration.

Measure and inspect

Compare image ranking, false alarms, and defect recall. Score localization against the original annotations reduced to the model grid.

The benchmark covers one board category. The gallery includes precomputed examples of correct decisions, missed defects, and false alarms. All 200 test images contribute to the reported metrics.
