Evidence summary

    Model validation

    Four rolling seven-day backtests compare ridge regression with the previous week’s daily pattern. The lower-error method is selected for each borough. This is backtest error used for selection, so it can be optimistic.

    Download backtest predictions

    Business analysis & data engineering

    From request counts to a planning decision

    01

    Define demand

    Count requests created per borough and day. A planner can enter a daily handling capacity and see the forecast days and volume above it.

    02

    Build the data feed

    Aggregate by date and borough, exclude the latest observed day as a precaution, validate all 700 borough-day rows, and export a reporting table.

    03

    Forecast and explain

    Train on earlier dates, compare against a weekly baseline, then draft a planning brief from the same evidence shown on the dashboard.

    The feed measures requests reported to 311. It does not measure all incidents, staff productivity, or confirmed staffing needs. Recent source dates may be revised.
