Power BI setup

Build the same demand planning view using the validated borough-day table. The report calculates a staffing scenario in requests per day.

Download Power QueryDownload DAXMicrosoft Web connector guide ↗

Import and model

  1. In Power BI Desktop, choose Get Data → Blank Query. Open Advanced Editor, paste the Power Query file, and name the query Demand. Use Anonymous credentials for the published source.
  2. For an offline file, export Power BI CSV from the dashboard, set UsePublished to false, and set CsvPath to the downloaded file. Simulated exports have a simulated- prefix.
  3. Close & Apply. Add the three calculated tables and then the individual measures from the DAX file.
  4. Create single-direction, one-to-many relationships from Dates[Date] to Demand[day] and from Boroughs[borough] to Demand[borough]. Leave Capacity disconnected. Use a single-select borough slicer.

Build the report page

01

Scenario controls

Add single-select Borough and Capacity slicers. Capacity means daily requests that could be handled in the selected borough.

02

Trend and KPIs

Plot Date against Observed Requests, Forecast Requests and Capacity Line. Add cards for Forecast Requests, Days Over Capacity, Volume Above Capacity and Last Observed Day.

03

Validate the result

Use the same borough and capacity in both reports, and include all seven forecast days. Check that forecast volume, days over capacity, and volume above capacity match.
